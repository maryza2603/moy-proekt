# FL.ru для Android

Приложение-обёртка для биржи FL.ru: сайт открывается внутри приложения, вход сохраняется, а в фоне раз в 15 минут проверяются непрочитанные сообщения и события - при появлении новых приходит уведомление.

## Что умеет
- Открывает FL.ru, вход запоминается между запусками
- Кнопка "Назад" листает историю страниц
- Можно прикреплять файлы к откликам и сообщениям
- Фоновая проверка непрочитанного каждые 15 минут и push-уведомление

## Сборка
```
./gradlew assembleRelease
```
APK: `app/build/outputs/apk/release/app-release.apk`
